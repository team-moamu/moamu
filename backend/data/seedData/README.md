# SeedData

로컬 개발용 단일 시드 파일을 보관하는 폴더입니다.

대상 스키마는 `backend/src/main/resources/db/migration`의 **Flyway V1~V4 적용 결과**입니다. 스키마와 Flyway 이력은 유지하고 도메인 데이터를 비운 뒤 [v1_seed-dev.sql](v1_seed-dev.sql) 전체를 한 번 실행합니다.

기본 데이터와 최종 영문 이미지 키를 한 번에 입력하므로 별도 경로 보정 SQL은 필요하지 않습니다. 데이터가 남아 있으면 실행을 중단하며, 시드 자체가 기존 데이터를 삭제하지는 않습니다.

기존 DB 구조가 다른 경우의 준비 방법, 실행 명령, 기대 건수와 S3 경로는 [상위 README](../README.md)를 참고합니다. 이미지 파일 자체는 저장하지 않고 S3 객체 키만 DB에 기록합니다.
